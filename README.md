# Product Sales Dashboard

## Project Overview

The Product Sales Dashboard project focuses on analysing product sales data to understand business performance, revenue generation, product demand, and sales trends.

An interactive dashboard was developed to visualize important sales metrics and provide meaningful business insights that support data-driven decision-making.

## Project Objectives

- Analyse overall product sales performance.
- Identify top-selling products.
- Monitor total revenue and profit.
- Analyse monthly and yearly sales trends.
- Compare product category performance.
- Identify high-performing and low-performing products.
- Understand regional sales distribution.

## Tools & Technologies

- Tableau Public
- Microsoft Excel
- Data Cleaning
- Data Analysis
- Data Visualization
- Dashboard Development

## Dataset Description

The dataset contains product sales-related information, including product names, categories, sales transactions, revenue, profit, quantity, order dates, and geographical details.

## Key Performance Indicators (KPIs)

- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
- Average Order Value
- Profit Margin

## Dashboard Features

- Overall Sales Performance Analysis
- Product-wise Sales Analysis
- Category-wise Sales Analysis
- Monthly Sales Trend Analysis
- Profit Analysis
- Regional Sales Analysis
- Top 10 Products Analysis
- Interactive Dashboard Filters

## Key Insights

- Analysed overall product sales and profit performance.
- Identified the highest-performing products.
- Compared revenue across product categories.
- Evaluated monthly sales trends.
- Analysed regional sales performance.
- Identified products contributing significantly to overall revenue.
